# 🎓 AI Career Guidance Chatbot

An interactive web application built with **Python and Streamlit** that helps students discover suitable career paths based on their interests, skills, education, and goals.

### 🚀 Live Demo
[Try the AI Career Guidance Chatbot](https://ai-career-guidance-shathana.streamlit.app/)

### ✨ Key Features
- **Personalized Recommendations:** Suggests the top 3 careers based on the student's profile.
- **Career Match Score:** Calculates compatibility using interests, skills, and education.
- **Career Insights:** Explains why each recommended career is suitable.
- **Learning Guidance:** Suggests relevant courses and skills to develop.
- **Feedback System:** Collects user ratings and optional comments.
- **Input Validation:** Ensures valid inputs with clear error messages.
- **Error Handling:** Manages missing data and application errors gracefully.
- **Automated Testing:** Tests core functionality using pytest.

### 🛠️ Tech Stack
- Python
- Streamlit
- JSON and CSV
- pytest

### ⚙️ Run Locally

**1. Clone the repository**
```bash
git clone https://github.com/shathanasri12/AI-Career-Guidance-Chatbot.git
cd AI-Career-Guidance-Chatbot
```

**2. Install dependencies**
```bash
pip install -r requirements.txt
```

**3. Start the application**
```bash
python -m streamlit run app.py
```

Open the local URL displayed in your terminal to use the application.

### 🧪 Run Tests
```bash
python -m pytest -v
```
